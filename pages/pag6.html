Sistemas Numéricos

El sistema binario es un sistema de numeración que utiliza solo dos dígitos: 0 y 1. A diferencia del sistema decimal (base 10) que emplea diez cifras, el binario es de base 2. Cada dígito binario recibe el nombre de bit (binary digit). Este sistema es fundamental en electrónica digital e informática, ya que los circuitos electrónicos trabajan con dos estados: apagado (0) y encendido (1), lo que facilita el procesamiento y almacenamiento de datos en computadoras.

En el sistema binario, el valor posicional de cada bit es una potencia de 2, comenzando desde 2⁰ (unidades), luego 2¹ (dos), 2² (cuatro), 2³ (ocho), 2⁴ (dieciséis), etc. Por ejemplo, el número binario 1011 se interpreta como: 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11 en decimal. Gracias a esta estructura, cualquier número decimal puede representarse mediante combinaciones de unos y ceros.

Para convertir un número decimal a binario, se utiliza el método de divisiones sucesivas entre 2. Se divide el número decimal entre 2, se anota el residuo (que será 0 o 1) y se continúa dividiendo el cociente obtenido entre 2, repitiendo el proceso hasta que el cociente sea 0. El número binario se lee tomando los residuos en orden inverso (del último al primero). Por ejemplo, para convertir 13: 13 ÷ 2 = 6 residuo 1; 6 ÷ 2 = 3 residuo 0; 3 ÷ 2 = 1 residuo 1; 1 ÷ 2 = 0 residuo 1. Leyendo los residuos de abajo arriba: 1101, que es 13 en binario.

Otro ejemplo: convertir 25 a binario. 25 ÷ 2 = 12 residuo 1; 12 ÷ 2 = 6 residuo 0; 6 ÷ 2 = 3 residuo 0; 3 ÷ 2 = 1 residuo 1; 1 ÷ 2 = 0 residuo 1. Entonces 25 decimal equivale a 11001 binario. Este método funciona para cualquier número entero positivo. Para números fraccionarios se usa multiplicaciones sucesivas por 2, pero lo más común es trabajar con enteros en los fundamentos de la informática.
