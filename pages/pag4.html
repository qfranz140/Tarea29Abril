Sistema Operativo Información Ejemplos / Versiones
Windows Desarrollado por Microsoft (1985). Es el SO más popular en ordenadores personales. Interfaz gráfica intuitiva, amplia compatibilidad con software y juegos. Ha evolucionado desde MS-DOS hasta Windows 11. Soporta aplicaciones empresariales, domésticas y de servidor. Windows 95, Windows XP, Windows 7, Windows 10, Windows 11, Windows Server
Linux Núcleo (kernel) creado por Linus Torvalds (1991). Es de código abierto y gratuito. Existen múltiples distribuciones (Debian, Ubuntu, Fedora, etc.). Muy estable, seguro y personalizable. Usado en servidores, supercomputadoras, dispositivos embebidos y también en escritorio. Ubuntu, Debian, CentOS, Red Hat, Arch Linux, Linux Mint, Kali Linux
macOS Desarrollado por Apple (2001), basado en Unix. Exclusivo para hardware Mac. Destaca por su estabilidad, diseño elegante, ecosistema integrado con iOS y servicios Apple. Incluye herramientas como Safari, iMovie y la terminal Unix. Sucesor de Mac OS Classic. Mac OS X Cheetah, macOS Mojave, macOS Big Sur, macOS Monterey, macOS Ventura, macOS Sonoma
Android Creado por Google (2008), basado en el núcleo Linux. Es el SO móvil más utilizado del mundo. Código abierto (AOSP) pero con servicios Google propietarios. Permite multitarea, notificaciones, tienda de aplicaciones (Play Store). Personalizable por fabricantes como Samsung, Xiaomi, Motorola. Android Cupcake (1.5), Android Pie (9), Android 10, Android 13, Android 14, One UI, MIUI
iOS Desarrollado por Apple (2007) exclusivamente para iPhone, iPod Touch y iPad (este último usa iPadOS derivado). Interfaz táctil fluida, alto rendimiento, ecosistema cerrado pero seguro. App Store con estrictos controles de calidad. Actualizaciones directas y duraderas. iOS 4, iOS 7, iOS 11, iOS 14, iOS 16, iOS 17, iPhone OS 1
